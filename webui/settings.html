TunGuard configuration reference

Dashboard Login

Change the username and password used to access this dashboard. The same login is used for the SSH gateway.

API Key

API requests to /api/* are authenticated with this key (sent as the X-API-Key or Authorization: Bearer header). The dashboard login also works. Regenerating immediately invalidates the old key — update any integrations that use it.

Backup & Restore

Download a backup of all server state (peers, server key, dashboard login, SSH host key). Restoring never touches the binary or the service configuration — peers and keys are only replaced if the backup contains them.
